# Память Азерота

Игра на поиск пар в духе World of Warcraft. На поле 16 карточек: восемь героев и существ Азерота, каждый встречается дважды. Нужно открывать карточки по две и найти все пары за наименьшее число ходов.

Персонажи: мурлок, дракон, рыцарь смерти, маг, орк-воин, паладин, друид и гоблин.

## Как играть

1. Нажмите на закрытую карточку, затем на вторую.
2. Если изображения совпали, пара остаётся открытой.
3. Если нет, карточки закроются примерно через секунду. Пока они открыты, выбрать другие нельзя.
4. После восьми пар откроется окно победы с числом ходов.
5. Кнопка «Новая игра» перемешивает поле и обнуляет счётчики.
6. «Таблица лидеров» показывает до 10 лучших результатов. Они сохраняются в `localStorage`.

## Запуск

Откройте `index.html` двойным щелчком. Сервер не нужен: скрипт подключён как обычный файл, без модулей.

## Структура

- `index.html` — пустой `body`, подключение стилей и одного скрипта.
- `js/main.js` — страница сверху вниз: вёрстка, затем поведение кнопок «Новая игра», карточек и «Таблица лидеров».
